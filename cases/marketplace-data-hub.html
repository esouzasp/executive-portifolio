Marketplace Data Hub

Built a marketplace data hub integrating Amazon, Magalu, Mercado Livre, Inter, Fast Shop, Carrefour, Leroy Merlin and KaBuM.

8marketplaces integrated

Situation
Samsung's e-commerce operation in Brazil covers B2C, D2C and O2O through its own eStore and the main marketplaces, with logistics in the middle and last mile.
Task
Each marketplace had its own data and integration format, so there was no unified view of marketplace operations.
Action
As Manager of Supply Chain Projects & Data Analytics, led the marketplace data hub that consolidates data from Amazon, Magalu, Mercado Livre, Inter, Fast Shop, Carrefour, Leroy Merlin and KaBuM into the e-commerce data platform, refreshed every hour.
Result
  • 8 marketplaces integrated in one data hub, refreshed hourly
  • Supply chain team using it to spot errors and track order status along the chain
  • Input for the end-to-end supply chain control tower
