MPS Optimization Solver

Replaced manual master production scheduling with a linear optimization model feeding S&OP.

Situation
A large chemical company runs a master production schedule (MPS) that balances demand, capacity and inventory and feeds the S&OP.
Task
MPS planning was done manually, making it slow to rebuild and hard to optimize.
Action
Developed an optimization model in Excel + Solver that generates the production plan with a linear solver, within the planners' existing environment.
Result
  • Optimized MPS process with a linear solver
  • Production plan delivered for the S&OP
  • Faster replanning in a familiar tool
