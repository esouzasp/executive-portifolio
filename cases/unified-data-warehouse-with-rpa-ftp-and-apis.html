Unified Data Warehouse with RPA, FTP & APIs

Unified data warehouse fed by RPAs, FTP and APIs.

Situation
Operational data came from systems and partners with very different access methods, including some with no direct integration available.
Task
Without a way to bring these sources together, analytics stayed fragmented across files and manual extractions.
Action
As Manager of Supply Chain Projects & Data Analytics, bridging business requirements with the data and development teams, combined RPA bots, FTP transfers and APIs — with the indirect RPA team — to feed a single data warehouse.
Result
  • Single data warehouse consolidating RPA, FTP and API sources
  • Sources without native integration made available for analytics
  • Fewer manual extractions
