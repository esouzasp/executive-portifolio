Agentic Data Quality for o9 Pipelines

Led a data quality tool that combines a deterministic model and an agentic model to assess data quality in the pipelines that feed the o9 planning solution.

Situation
The o9 planning solution depends on complete, consistent data arriving through the corporate data pipelines.
Task
Rule-based checks alone do not catch every issue, and data quality problems in the pipelines put planning outputs at risk.
Action
As Senior Manager of Enterprise Data & Analytics, led the architecture design and the engineering team that built a data quality tool with two layers: a deterministic model of rules and checks, and an agentic model in which AI agents evaluate data quality in the pipelines that feed o9.
Result
  • Deterministic and agentic data quality checks on the o9 pipelines
  • Data quality issues surfaced before they reach planning
  • Data quality assessment built into the pipelines
