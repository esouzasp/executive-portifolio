Data Engineering Portfolio & Delivery Management (DataPlan)

Built DataPlan, a product to manage the data engineering portfolio and delivery — from intake and refinement to portfolio view and daily follow-up.

Situation
Data engineering serves all retail areas, with demands arriving as projects, changes and incidents from commercial, supply chain, manufacturing and operations.
Task
Demand intake, prioritization and delivery follow-up were spread across tools, with no single view of the portfolio for the team and stakeholders.
Action
Designed and is building DataPlan, an application that covers Intake, Refine, Portfolio and a Daily Room for follow-up. Work is organized as Epic (program), Feature (project) and Story (task), with separate demand types for projects, changes and incidents; changes are validated first in a prototype before aligning the backend.
Result
  • Single flow from demand intake to delivery follow-up
  • Portfolio view by program, project and task
  • Projects, changes and incidents managed as distinct demand types
