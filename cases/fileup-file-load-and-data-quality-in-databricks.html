FileUp — File Load & Data Quality in Databricks

Led design and implementation of FileUp: managed file uploads into Databricks with data quality checks on every load.

Situation
Commercial, supply chain, manufacturing and operations teams regularly need to bring file-based data — plans, parameters, supplier and manual inputs — into the lakehouse.
Task
File loads were not managed: there was no standard way to upload, no data quality control and no traceability of what entered the platform.
Action
As Senior Manager of Enterprise Data & Analytics, led the architecture design and the engineering team that delivered FileUp in Databricks, a governed path for file uploads with data quality checks applied on every load. It is part of the data governance work, together with lineage mapping and data quality tooling.
Result
  • Governed, self-service file loads into Databricks
  • Data quality checks applied on every load
  • Part of the data governance toolset alongside lineage mapping
