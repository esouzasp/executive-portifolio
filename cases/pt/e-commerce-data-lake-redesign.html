Redesenho do Data Lake de E-commerce

Redesenho do data lake de e-commerce com dados batch e streaming, viabilizando uma control tower centralizada.

Situação
A operação de e-commerce depende de dados integrados de comercial, supply e logística para construir uma jornada do cliente que conecte e-commerce e operações.
Tarefa
O ambiente SAP HANA tinha pouca variedade e baixa qualidade de dados, e o pipeline do eStore rodava como ETL, limitando novos usos como uma control tower.
Ação
Como Manager de Supply Chain Projects & Data Analytics, fazendo a ponte entre os requisitos do negócio e os times de dados e desenvolvimento, liderou as frentes de dados de e-commerce, supply e logística, redesenhando o data lake com dados batch e streaming e o pipeline do eStore de ETL para ELT no SAP HANA.
Resultado
  • Data lake entregue com dados batch e streaming
  • Pipeline do eStore redesenhado de ETL para ELT no SAP HANA
  • Base para o projeto de control tower centralizada
