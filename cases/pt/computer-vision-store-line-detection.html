Visão Computacional para Detecção de Filas nas Lojas

Revisão do pipeline de dados da visão computacional com IA que detecta filas nas lojas, e definição de como escalá-lo.

Situação
A Riachuelo usa visão computacional com IA para detectar filas de clientes nas lojas. Os dados de detecção precisam chegar à plataforma analítica para serem usados pela operação de lojas.
Tarefa
O projeto original de pipeline para ingerir os dados de visão computacional tinha lacunas, e não estava claro o que processar na borda e o que processar na plataforma.
Ação
Revisou o projeto de pipeline e suas lacunas com o time de engenharia de dados e os parceiros da solução, e liderou a decisão de trade-off sobre o que processar e onde, como base para escalar a solução.
Resultado
  • Plano para escalar a solução com engenharia de dados
  • Decisão clara de trade-off sobre o que processar e onde
  • Caminho dos dados de filas definido até a plataforma analítica
