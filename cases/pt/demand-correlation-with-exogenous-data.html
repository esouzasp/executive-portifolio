Correlação de Demanda com Dados Exógenos

Explicação dos picos de demanda com fatores exógenos, com forte correlação defasada com dados de mercado de fornecedores asiáticos.

Defasagem 6correlação, fornecedores asiáticos

Situação
Uma grande empresa de saúde animal enfrentava picos de demanda que afetavam estoques e nível de serviço.
Tarefa
Só com o histórico interno, os picos pareciam imprevisíveis, e o forecast não conseguia antecipá-los.
Ação
Conduziu um estudo para descobrir fatores exógenos por trás dos picos, correlacionando dados do mercado de ações — incluindo fornecedores asiáticos — com a demanda, para usar como sinais antecedentes no forecast.
Resultado
  • Alta correlação com defasagem de 6 períodos para fornecedores asiáticos
  • Sinais exógenos antecedentes disponíveis para melhorar o forecast
  • Explicação para picos antes vistos como imprevisíveis
