Ingestão de Dados de Mais de 100 Novas Fontes

Pipelines de ingestão de mais de 100 novas fontes de dados no SAP HANA com Pentaho, Talend e T-SQL.

100+novas fontes de dados

Situação
O analytics de supply chain, e-commerce e logística precisava de dados de muitas fontes novas para construir a visão ponta a ponta.
Tarefa
As novas fontes precisavam ser ingeridas de forma confiável no data warehouse corporativo em SAP HANA, com formatos e ferramentas muito diferentes.
Ação
Como Manager de Supply Chain Projects & Data Analytics, fazendo a ponte entre os requisitos do negócio e os times de dados e desenvolvimento, liderou os pipelines de ingestão com Pentaho, Talend e T-SQL no SAP HANA, e os data marts e relatórios analíticos sobre eles, gerindo um time de supervisor, analistas e consultores.
Resultado
  • Mais de 100 novas fontes de dados ingeridas no SAP HANA
  • Diversos data marts e relatórios descritivos e preditivos
  • Base de dados para a control tower e o analytics de e-commerce
