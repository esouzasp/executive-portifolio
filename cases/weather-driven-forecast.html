Weather-Driven Forecast

Weather-driven daily forecasting for an ice cream manufacturer, cutting forecast error (MAPE) from 60% to 35%.

60→35%forecast error (MAPE)

Situation
A mid-size ice cream manufacturer plans production and distribution on a daily basis, and ice cream demand is highly sensitive to weather.
Task
The forecast did not use weather data, so daily accuracy dropped exactly when weather changed demand.
Action
Scraped weather data from INMET (Brazil's national weather institute), combined it with sales history and built daily forecasts in Python with Prophet, for 7-day and 15-day horizons.
Result
  • Forecast error (MAPE) reduced from 60% to 35%
  • +30 pp accuracy in the 7-day daily forecast
  • +20 pp accuracy in the 15-day daily forecast
  • Weather data built into daily planning
