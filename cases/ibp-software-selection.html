IBP Software Selection

Led the evaluation of IBP and supply chain planning tools with a data architecture fit analysis.

Situation
Riachuelo was selecting a new integrated business planning (IBP) / supply chain planning platform to connect commercial, supply and manufacturing plans.
Task
Choosing a tool only on features, without assessing how it fits the data landscape, risked a non-scalable architecture after contracting.
Action
Conducted demo workshops with the vendors and a data architecture fit analysis for each option, mapping the static and dynamic input data the planning platform would need.
Result
  • Non-scalable architecture risks anticipated before contracting
  • Static and dynamic input data mapped for the planning platform
  • Selection based on business fit and data architecture fit
