Rediseño del Data Lake de E-commerce

Rediseñó el data lake de e-commerce con datos batch y streaming, habilitando una control tower centralizada.

Situación
La operación de e-commerce depende de datos integrados comerciales, de abastecimiento y de logística para construir una jornada del cliente que conecte e-commerce y operaciones.
Tarea
El entorno SAP HANA tenía poca variedad y baja calidad de datos, y el pipeline del eStore funcionaba como ETL, lo que limitaba nuevos usos como una control tower.
Acción
Como Manager de Supply Chain Projects & Data Analytics, haciendo de puente entre los requisitos del negocio y los equipos de datos y desarrollo, lideró los frentes de datos de e-commerce, abastecimiento y logística, rediseñando el data lake con datos batch y streaming y el pipeline del eStore de ETL a ELT en SAP HANA.
Resultado
  • Data lake entregado con datos batch y streaming
  • Pipeline del eStore rediseñado de ETL a ELT en SAP HANA
  • Base para el proyecto de control tower centralizada
