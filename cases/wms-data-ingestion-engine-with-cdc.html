Enterprise Data Platforms · Riachuelo

WMS Data Ingestion Engine with CDC

Led design and implementation of an ingestion engine for about 20K WMS tables using change data capture (CDC).

20KWMS tables in scope

Situation
Riachuelo's logistics runs through 3 distribution centers serving more than 430 stores. WMS data is essential for order flow, inventory and logistics analytics, but the WMS database has around 20K tables.
Task
Ingesting a WMS of that size with full reloads would not scale, and keeping logistics data current required capturing only what changed.
Action
As Senior Manager of Enterprise Data & Analytics, led the design of a change data capture (CDC) ingestion engine for the WMS and the engineering team for delivery: defining the CDC approach, the ingestion pattern for the table landscape and how the data lands on the platform alongside the logistics order flow.
Result
  • Ingestion design covering about 20K WMS tables
  • CDC approach that captures only changes and keeps data current
  • WMS data integrated with the logistics order flow on the data platform
