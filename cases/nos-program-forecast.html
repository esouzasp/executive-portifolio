NOS Program Forecast

Turned an Excel forecast into a scalable Databricks model for never-out-of-stock (NOS) programs.

25→19%MAPE, women's category

Situation
Never-out-of-stock (NOS) programs keep core items continuously available across more than 430 stores, which depends on reliable forecasts.
Task
Forecast accuracy for the programs was low, and the forecast lived in an Excel tool that could not scale.
Action
Productized the Excel forecasting tool so it could scale, delivering the model in Databricks as a quick win while the broader planning evolution continued.
Result
  • Women's category MAPE reduced from 25% to 19%
  • Forecast model running in Databricks
  • Quick win delivered from an Excel tool to a scalable model
