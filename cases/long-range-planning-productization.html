Long-Range Planning Productization

Turned a long-range planning tool built in Excel and Power BI into a PySpark data product on Azure Synapse.

Situation
A large Latin American beverage bottler used a long-range planning (LRP) tool, built in Excel and Power BI, to support capacity and investment decisions.
Task
The LRP tool needed to become a product that could run in the client's cloud environment and scale beyond one operation.
Action
Led the architecture and built the data pipeline in PySpark on the client's Azure Synapse environment, turning the spreadsheet logic into a data product.
Result
  • Tool running in the client's Azure Synapse environment
  • LatAm bottler ready to scale the solution globally
  • LRP logic moved from spreadsheets to a data product
