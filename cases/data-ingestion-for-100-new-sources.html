Data Ingestion for 100+ New Sources

Ingestion pipelines for 100+ new data sources into SAP HANA using Pentaho, Talend and T-SQL.

100+new data sources

Situation
Supply chain, e-commerce and logistics analytics needed data from many new sources to build the end-to-end view.
Task
New sources had to be ingested reliably into the corporate SAP HANA data warehouse, with very different formats and tools.
Action
As Manager of Supply Chain Projects & Data Analytics, bridging business requirements with the data and development teams, led the ingestion pipelines built with Pentaho, Talend and T-SQL into SAP HANA, and the data marts and analytics reports on top of them, managing a team of supervisor, analysts and consultants.
Result
  • 100+ new data sources ingested into SAP HANA
  • Numerous data marts and descriptive and predictive reports
  • Data foundation for the control tower and e-commerce analytics
